# 🎂 Age Calculator

An interactive and stylish web application that calculates a person's exact age in years, months, and days based on a selected birthdate. It includes built-in leap year validation and future-date checks.

## 🚀 Features
* Precise calculation of age broken down into years, months, and days[cite: 22].
* Built-in leap year checker (`leapChecker`) for accurate February day counts[cite: 22].
* Validation alerts to prevent selecting future dates ("Not Born Yet")[cite: 22].
* Modern dark-themed container cards with smooth shadows against a vibrant blue background[cite: 20].

## 🛠 Technologies Used
* **HTML5** (Date input fields, semantic structure)[cite: 21]
* **CSS3** (Flexbox, custom button/input styling, absolute centering)[cite: 20]
* **JavaScript** (Date object manipulation, algorithmic age breakdown, DOM updates)[cite: 22]

## 💻 How to Run
1. Clone or download this repository.
2. Open `index.html` in any web browser[cite: 21].

# 🎂 Калькулятор возраста (Age Calculator)

Интерактивное и стильное веб-приложение, которое вычисляет точный возраст человека в годах, месяцах и днях на основе выбранной даты рождения. Включает встроенную проверку високосных лет и защиту от выбора будущей даты.

## 🚀 Особенности
* Точный расчет возраста с разбивкой на годы, месяцы и дни[cite: 22].
* Встроенная проверка високосных годов для правильного расчета дней в феврале[cite: 22].
* Проверка на некорректные даты (предупреждение при выборе даты из будущего)[cite: 22].
* Современный дизайн в темных тонах с красивыми тенями на ярко-синем фоне[cite: 20].

## 🛠 Используемые технологии
* **HTML5** (поля ввода дат, семантическая разметка)[cite: 21]
* **CSS3** (Flexbox, стилизация полей ввода и кнопок, центрирование)[cite: 20]
* **JavaScript** (работа с объектами Date, алгоритм расчета возраста, обновление DOM)[cite: 22]

## 💻 Как запустить
1. Клонируйте или скачайте этот репозиторий.
2. Откройте файл `index.html` в любом веб-браузере[cite: 21].
